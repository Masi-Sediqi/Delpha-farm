مرحله سوم: کنترل صلاحیت Backend برای Collectionها

1. ابتدا از transport-backend/server.js و PostgreSQL بکاپ بگیرید.
2. فایل اصلاح شده را با رعایت مسیر در D:\Delpha-farm جایگزین کنید.
3. node --check transport-backend/server.js
4. npm run start:api و npm run dev:production
5. با حساب محدود، خواندن بخش مجاز، عدم دسترسی به بخش غیرمجاز و ایجاد/ویرایش/حذف مجزا را آزمایش کنید.

محدودیت مهم: نوشتن مجموعه های مالی برای کاربر عادی هنوز بسته است تا تراکنش سروری اتمیک و audit اجرا شود.
مجوز چاپ را Backend برای endpoint های چاپ جداگانه اعمال نمی کند؛ چاپ سمت کلاینت نیازمند بازبینی است.
دسترسی خواندن برای کاربران عادی بر اساس داشتن حداقل یکی از مجوزهای create/edit/delete/print است.
فهرست مجموعه های ناشناخته و حساس برای کاربران عادی مسدود می ماند.
این بسته بدون migration دیتابیس است و هیچ رکوردی را حذف نمی کند.
نسخه اصلاحی مرحله دوم مبنای این فایل بوده است.
