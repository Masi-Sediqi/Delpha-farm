# Delpha-farm secure stage

این بسته فقط فایل‌های تغییرکرده را دارد. فایل‌های قبلی را با ساختار همین ZIP جایگزین کن.

## موارد انجام‌شده
- ورود با PostgreSQL session و HTTP-only cookie
- محافظت از API و محدود کردن دسترسی به حساب Admin
- عدم ذخیره داده تجاری در IndexedDB در production
- جلوگیری از overwrite هم‌زمان با If-Match
- ساخت Admin با scripts/create-delpha-admin.mjs

## محدودیت‌ها
- مدیریت کاربران قدیمی هنوز به سیستم کاربران سروری مهاجرت نکرده است؛ مرحله اول فقط Admin را پشتیبانی می‌کند.
- قبل از تغییر Nginx، تست‌های داخلی را کامل کن.
- داده‌های قدیمی به صورت خودکار وارد نمی‌شوند.
- این ZIP خودکار روی GitHub یا VPS منتشر نشده است.
