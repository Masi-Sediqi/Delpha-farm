# APG Medicine Management

Pharmacy & Medicine Management System built with React + Vite.

## Environment modes

- Demo: `npm run dev:demo` / `npm run build:demo`
- Production: `npm run dev:production` / `npm run build:production`

Demo and Production use separate browser-storage namespaces. For a Vercel customer deployment, set `VITE_APP_MODE=production`.

## Core modules

Dashboard, Manufacturers, Suppliers, Products, Purchasing, Customers, Sales, Inventory, Cash Flow, Reports, Settings, returns, payments, expenses, banks, cash count, and accounting journal.

## Note

The current browser-storage version is suitable for demo/testing. A shared production deployment should use a real backend/database.
