مرحله چهارم: تراکنش اتمیک خریداری و فروشات

فایل ها را در D:\Delpha-farm با حفظ ساختار پوشه ها جایگزین نمایید.
پیش از نصب از PostgreSQL و فایل های پروژه بکاپ بگیرید.
دستورها:
  node --check transport-backend/server.js
  npm run build
  npm run start:api
  npm run dev:production

تغییرات:
- خریداری: 4 مجموعه purchases,purchaseItems,stockMovements,products در یک BEGIN/COMMIT.
- فروشات: 2 مجموعه salesRegister,stockMovements در یک BEGIN/COMMIT.
- هر اختلاف نسخه 409 باعث ROLLBACK همه تغییرات می شود.
- در این مرحله عملیات اتمیک فقط به Admin مجاز است.

محدودیت مهم:
- این اصلاح فقط فورم ثبت و ویرایش خرید و فروش را پوشش می دهد، نه برگشت و حذف و پرداخت.
- اعتبارسنجی سروری منطق محاسبه موجودی و جلوگیری از فروش بیش از موجودی هنوز تکمیل نشده.
- داده های قدیمی تغییر نمی کنند. قبل از استفاده زنده تست کامل ضروری است.
- داده های چند مرورگر در زمان همزمانی ممکن است conflict شوند؛ فرم را دوباره بارگذاری و بررسی کنید.
- فایل ها از نسخه آخر موجود در گفتگو + پچ مرحله سوم تهیه شده اند. تغییرات محلی جدیدتر را قبل از جایگزینی مقایسه کنید.
