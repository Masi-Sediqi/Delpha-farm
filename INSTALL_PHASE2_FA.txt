مرحله دوم APG: مدیریت کاربران در PostgreSQL

پیش از نصب: از پروژه و PostgreSQL بکاپ بگیرید.
فایل‌ها را در D:\Delpha-farm با همان مسیر جایگزین کنید.
Backend و Frontend را ریستارت کنید: npm run start:api ، npm run dev:production
سپس npm run build را بررسی کنید.

حساب‌های موجود delpha_users حذف نمی‌شوند. ستون permissions به‌طور افزایشی ایجاد می‌شود.
مدیریت Settings > Users اکنون از مسیرهای /api/admin/users استفاده می‌کند.
حساب Admin فعلی از این فورم قابل حذف یا تغییر نیست.
تغییرات رمز و صلاحیت یک کاربر، Sessionهای همان کاربر را باطل می‌کند.

محدودیت ایمنی: کاربر غیرادمین هنوز به collection API دسترسی کامل ندارد.
تا مرحله بررسی جزئی مجوزهای ثبت، ویرایش و حذف، نباید دسترسی مالی وسیع باز شود.
آزمایش کامل اتصال به PostgreSQL زنده و تست چندکاربری روی سیستم کاربر انجام نشده است.
